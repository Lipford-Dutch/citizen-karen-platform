# Contributing

Thank you for improving Citizen Karen. Changes should make civic filing clearer, safer, or more accessible without overstating an agency integration.

1. Open or reference an issue that describes the citizen outcome and privacy implications.
2. Branch from `main` and keep the change focused.
3. Use synthetic data only. Never commit complaint content, personal information, tracking IDs, credentials, or local databases.
4. Run the complete verification suite in the root README.
5. Update tests, API contracts, and documentation with behavior changes.
6. Open a pull request using the repository template.

New agency automation requires legal-risk, consent, data-minimization, accessibility, connector-failure, and fallback review. A directory link to an official site is preferred until those checks are complete.

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md) and report vulnerabilities through [private security advisories](SECURITY.md).
