# Accepted visual direction

The three concepts in `concepts/` define the release-candidate visual system: true white surfaces, deep navy typography, cobalt actions, restrained red accents, generous civic wayfinding imagery, open divider-based lists, and plain-language trust cues.

The implementation follows the concepts for the destination directory, FCC filing flow, and tracking status. It uses the repository's existing raster brand mark and a purpose-built transparent wayfinding illustration; it does not claim affiliation with a government agency.
