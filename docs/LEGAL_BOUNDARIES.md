# Legal & Automation Boundaries — Karing USA

## Core Rule
Karing USA acts as a **digital scribe and routing agent**, not an impersonator.

---

## Explicit Restrictions

❌ No credential sharing  
❌ No login to identity-protected portals  
❌ No bypassing CAPTCHA or MFA  
❌ No pretending to be user  

✅ Allowed:
✔ API submission
✔ Public form automation
✔ User-authenticated uploads
✔ PDF generation + e-signature (where permitted)

---

## Required Safeguards

- Explicit user authorization
- Per-agency compliance review
- Automation kill-switch per module
- Manual-review fallback mode

---

## Disclaimer Requirement
Each agency module must declare:
- Automation method used
- Known restrictions
- Legal caveats
