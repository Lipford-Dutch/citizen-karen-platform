# Citizen Karen documentation

Citizen Karen is a civic wayfinding and complaint-intake prototype. The current release candidate provides a complete local FCC filing path while directing every unsupported destination to its official government website.

## Current release boundary

- **Implemented:** 28-destination directory, FCC intake and consent, simulated or mocked submission, durable local receipt, tracking, deletion, responsive UI, and automated checks.
- **Not represented as production-ready:** real FCC transmission, user authentication, multi-tenant storage, distributed rate limiting, encrypted managed storage, legal approval, or a live public deployment.
- **Safety rule:** an agency may become a direct integration only after technical, legal, accessibility, and data-governance review.
