# Security policy

## Supported versions

Security fixes are applied to the latest `1.x` release candidate on `main`.

## Report privately

Do not open a public issue for a vulnerability or include complaint content, personal information, secrets, or live tracking IDs in a report.

Use the repository's [private security advisory form](https://github.com/Lipford-Dutch/citizen-karen-platform/security/advisories/new). Include a concise impact statement, safe reproduction steps, affected commit or version, and a minimal proof of concept using synthetic data.

Maintainers will acknowledge the report when it is reviewed, coordinate remediation and disclosure with the reporter, and avoid requesting production personal data. This project does not currently operate a bug bounty program.

## Scope warning

The repository is a local engineering release candidate and is not approved for public production complaint data. See [implementation notes](docs/SECURITY.md) for the controls that must be completed before deployment.
